Para entrar

Três passos até estar estudando

Repositório privado

01

Peça acesso

O repositório da tradução é privado. Abra uma issue aqui com o seu usuário do GitHub e a Ana te adiciona como colaboradora ou colaborador.

Pedir acesso

Você recebe o convite por e-mail. Aceite antes de seguir para o passo 2.

02

Clone o repositório

Abra o Terminal (no Mac: Cmd+Espaço, digite Terminal) e cole as duas linhas abaixo, uma de cada vez:

cd ~/Documents
git clone https://github.com/PurpleRatatui/ccar-f-study-kit-ptbr.git

Se ele pedir usuário e senha, use o seu login do GitHub. A pasta ccar-f-study-kit-ptbr aparece dentro de Documentos.

03

Abra no VS Code com o Claude Code

  1. Instale o VS Code, se ainda não tiver.
  2. No VS Code, aperte Cmd+Shift+X, busque Claude Code (publicado pela Anthropic) e instale.
  3. File → Open Folder… e escolha a pasta ccar-f-study-kit-ptbr inteira. Abrir a pasta toda é o que ativa o modo tutor.
  4. Abra o painel do Claude e digite /progress. Se ele responder com seu progresso, está funcionando.

Você não precisa saber programar. Nos exercícios, você explica seu raciocínio em português e o Claude escreve o código. O que o exame mede é a decisão de projeto, não a sintaxe.

A premissa

Por que não traduzimos tudo

A prova é aplicada em inglês, e os termos são o jogo inteiro: stop_reason, end_turn, subagent, hook, MCP, context window. Se você aprende em português, chega no dia da prova traduzindo de cabeça contra o relógio.

Então: prosa, instruções e comentários em português. Termos técnicos, código, caminhos de arquivo, comandos e task statements em inglês, exatamente como aparecem na prova. A pasta sources/ fica inteira em inglês de propósito — é dela que o tutor cita literalmente o que o exame cobra. As regras completas estão no TRADUCAO.md.

Tradução não oficial do CCAR-F Study Kit, material criado pela Myosin. O kit original é público e gratuito; leia por lá se preferir em inglês. Esta tradução é de uso interno e não deve ser redistribuída.

O exame CCAR-F é da Anthropic. Confirme formato, taxa e nota de corte na página oficial de certificação antes de se inscrever — os números acima vêm do kit.
